# NoSQL Lab 04: Product Query API, Upserts, and Bulk Operations

NoSQL Lab 4: Advanced Query Operators, Upserts, and High-Throughput Bulk Operations

## Overview
E-commerce product catalog search API with complex filters, range queries, projection, bulk write execution (ordered/unordered), and upsert semantics.

## Repository Contents
- Python implementation scripts and exercises
- Comprehensive test runs and automated workflows
- Database schemas, configuration, and queries
- Benchmarks, analytics, and documentation

## Requirements
- Python 3.10+
- MongoDB 7.0+ (Local Community Edition or Atlas)
- Required packages: `pip install pymongo`
