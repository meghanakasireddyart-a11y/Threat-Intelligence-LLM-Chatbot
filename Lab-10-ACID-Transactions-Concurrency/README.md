# NoSQL Lab 10: Multi-Document ACID Transactions

NoSQL Lab 10: Multi-Document ACID Transactions and Concurrency Control

## Overview
Session-based multi-document distributed ACID transactions for bank fund transfers, inventory reservation under concurrent demand, and rollback guarantees.

## Repository Contents
- Python implementation scripts and exercises
- Comprehensive test runs and automated workflows
- Database schemas, configuration, and queries
- Benchmarks, analytics, and documentation

## Requirements
- Python 3.10+
- MongoDB 7.0+ (Local Community Edition or Atlas)
- Required packages: `pip install pymongo`
