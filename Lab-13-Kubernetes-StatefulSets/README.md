# NoSQL Lab 13: Kubernetes Deployment and StatefulSet Orchestration

NoSQL Lab 13: Containerized Database Orchestration with Kubernetes StatefulSets

## Overview
Deploying resilient MongoDB topologies on Kubernetes using StatefulSets, persistent volume claims (PVC), headless services, and automated replica set init.

## Repository Contents
- Python implementation scripts and exercises
- Comprehensive test runs and automated workflows
- Database schemas, configuration, and queries
- Benchmarks, analytics, and documentation

## Requirements
- Python 3.10+
- MongoDB 7.0+ (Local Community Edition or Atlas)
- Required packages: `pip install pymongo`
