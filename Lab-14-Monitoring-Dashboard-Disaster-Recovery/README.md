# NoSQL Lab 14: Monitoring Dashboard and Disaster Recovery

NoSQL Lab 14: Real-Time Server Metrics, Oplog Tailing, and Backup & Restore Workflows

## Overview
Real-time metrics polling (serverStatus, ops counter), WiredTiger cache utilization, mongodump/mongorestore automation, and point-in-time recovery with oplog.

## Repository Contents
- Python implementation scripts and exercises
- Comprehensive test runs and automated workflows
- Database schemas, configuration, and queries
- Benchmarks, analytics, and documentation

## Requirements
- Python 3.10+
- MongoDB 7.0+ (Local Community Edition or Atlas)
- Required packages: `pip install pymongo`
