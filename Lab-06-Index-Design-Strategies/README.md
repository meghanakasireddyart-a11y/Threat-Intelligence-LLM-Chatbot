# NoSQL Lab 06: Index Design and Compound Indexing Strategies

NoSQL Lab 6: Index Architecture, Compound Indexes (ESR Rule), and Execution Plan Analysis

## Overview
Single-field, compound, multikey, and text indexes; query planner analysis with explain('executionStats'), and ESR (Equality, Sort, Range) rule optimization.

## Repository Contents
- Python implementation scripts and exercises
- Comprehensive test runs and automated workflows
- Database schemas, configuration, and queries
- Benchmarks, analytics, and documentation

- Python 3.10+
- MongoDB 7.0+ (Local Community Edition or Atlas)
- Required packages: `pip install pymongo`
