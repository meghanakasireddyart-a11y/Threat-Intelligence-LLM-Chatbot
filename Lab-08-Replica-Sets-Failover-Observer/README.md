# NoSQL Lab 08: Replica Sets and Failover Observer

NoSQL Lab 8: High Availability Replica Sets, Heartbeats, and Automated Failover Simulation

Three-node replica set configuration, election protocols, primary stepping down, automatic failover detection, and client reconnection handling.

## Repository Contents
- Python implementation scripts and exercises
- Comprehensive test runs and automated workflows
- Database schemas, configuration, and queries
- Benchmarks, analytics, and documentation

- Python 3.10+
- MongoDB 7.0+ (Local Community Edition or Atlas)
- Required packages: `pip install pymongo`
