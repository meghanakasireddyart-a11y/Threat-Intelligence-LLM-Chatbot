# NoSQL Lab 18: Comparative Capstone Benchmark and Decision Report

NoSQL Lab 18: Comparative Capstone Benchmark (MongoDB vs Cassandra vs Neo4j) and Technical Report

## Overview
End-to-end multi-workload benchmark on 10,000 synthetic financial transactions, measuring point lookups, risk filtering, aggregation, and write throughput, with automated comparative analysis reporting.

## Repository Contents
- Python implementation scripts and exercises
- Comprehensive test runs and automated workflows
- Database schemas, configuration, and queries
- Benchmarks, analytics, and documentation

## Requirements
- Python 3.10+
- MongoDB 7.0+ (Local Community Edition or Atlas)
- Required packages: `pip install pymongo`
